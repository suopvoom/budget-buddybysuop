# Smart Shopper Hub

ROLE

You are a senior Product Manager, UI/UX Designer, Software Architect, and Startup Founder. Think like someone building the next successful shopping app.

Design a complete mobile application from scratch.

APP IDEA

I want to build a modern mobile application whose main purpose is price tracking and smart shopping decisions.

The app will initially focus only on Beauty & Personal Care products, but it must be designed in a scalable way so that I can later add:

Fashion

Clothing

Shoes

Watches

Bags

Electronics

Home Accessories

Grocery

and many other categories.

The app should feel premium, modern, fast, and addictive to use.

The design should be at the level of companies like Amazon, Nykaa, Myntra, Apple, and Google.

MAIN GOAL

Users should never miss a price drop.

Whenever the price of a tracked product decreases, they instantly receive a notification.

The app should help users answer one simple question:

"Should I buy this product today or wait?"
